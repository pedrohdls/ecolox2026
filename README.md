Para rodar o código

Acesse o terminal do VS Code e execute os seguintes comandos, certificando-se de que esteja dentro da pasta do projeto. Exemplo: C:\Downloads\ECOLOX2026>.

Execute npm install para instalar as dependências necessárias.

Execute npm run dev para iniciar o servidor de desenvolvimento.

A aplicação utiliza React e TypeScript para a construção da interface, Node.js e npm para o gerenciamento do ambiente e das dependências, Vite como ferramenta de desenvolvimento e Supabase como serviço de banco de dados.

O Supabase é responsável pelo armazenamento e gerenciamento das informações da aplicação, permitindo a persistência dos dados das coletas e das informações dos usuários. Além disso, oferece suporte ao sistema de autenticação utilizado no cadastro e login.

Durante a execução, o Vite inicia um servidor local que processa os módulos da aplicação e disponibiliza os arquivos para o navegador, permitindo visualizar e testar as funcionalidades em tempo real.

Após iniciar o servidor, acesse o endereço disponibilizado no terminal, geralmente http://localhost:5173/.
